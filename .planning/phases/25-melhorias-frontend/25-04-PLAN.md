**Fix 1: staff_dashboard_screen.dart (D-15) — lines 188-211**

The current structure is:
```dart
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Text('Taxa de Resolução Automatizada', ...),
    Text('${_calculateAiRate(dashboard)}%', ...),
  ],
),
```

The first `Text` is long and unwrapped, causing overflow on narrow screens. Fix by wrapping the first Text in `Expanded` and adding `overflow: TextOverflow.ellipsis`:

Change the Row children to:
```dart
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Expanded(
      child: Text(
        'Taxa de Resolução Automatizada',
        style: Theme.of(context)
            .textTheme
            .bodySmall
            ?.copyWith(
              color: colors.onSurface,
            ),
        overflow: TextOverflow.ellipsis,
      ),
    ),
    const SizedBox(width: 8),
    Text(
      '${_calculateAiRate(dashboard)}%',
      style: Theme.of(context)
          .textTheme
          .bodySmall
          ?.copyWith(
            fontWeight: FontWeight.bold,
            color: colors.onSurface,
          ),
    ),
  ],
),
```

The `SizedBox(width: 8)` ensures minimum spacing between label and percentage value.

**Fix 2: Also scan staff_dashboard_screen.dart for any other unwrapped Text in Row widgets and apply Expanded/Flexible where needed.** Common pattern: any Row with `mainAxisAlignment: MainAxisAlignment.spaceBetween` where one child is a long Text.

**Fix 3: login_screen.dart (D-17) — lines 422-434**

The OTP row generates 6 `SizedBox(width: 44, height: 52)` inside a `Row` with `MainAxisAlignment.spaceBetween`. Total minimum width = 6*44 = 264px. On iPhone SE (320dp), with padding the row might fit (320 - ~32 padding = 288 > 264), but it's close.

Read the parent padding/margin to verify. If the row has horizontal padding > 28px total, it will overflow.

If overflow risk exists, change `SizedBox(width: 44)` to `SizedBox(width: 40)` (6*40 = 240px, safe at 320dp even with 40px total padding). Alternatively, wrap each in `Flexible`:
```dart
Flexible(
  child: SizedBox(
    width: 44,
    height: 52,
    child: ...
  ),
)
```

This allows the boxes to shrink below 44px if needed while maintaining aspect ratio.
