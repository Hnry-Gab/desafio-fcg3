**Approach — use `rsvg-convert` (librsvg) or `convert` (ImageMagick):**

1. Check if `rsvg-convert` is available: `which rsvg-convert`
   - If available, use it (preferred — cleaner SVG rendering):
     ```bash
     rsvg-convert -w 16 -h 16 mobile/assets/logos/alpha_connect_shortlogo_dark.svg > /tmp/opencode/favicon-16.png
     rsvg-convert -w 32 -h 32 mobile/assets/logos/alpha_connect_shortlogo_dark.svg > /tmp/opencode/favicon-32.png
     rsvg-convert -w 192 -h 192 mobile/assets/logos/alpha_connect_shortlogo_dark.svg > /tmp/opencode/icon-192.png
     rsvg-convert -w 512 -h 512 mobile/assets/logos/alpha_connect_shortlogo_dark.svg > /tmp/opencode/icon-512.png
     ```
   - If not available, try `convert` (ImageMagick):
     ```bash
     convert -background none -resize 16x16 mobile/assets/logos/alpha_connect_shortlogo_dark.svg /tmp/opencode/favicon-16.png
     convert -background none -resize 32x32 mobile/assets/logos/alpha_connect_shortlogo_dark.svg /tmp/opencode/favicon-32.png
     convert -background none -resize 192x192 mobile/assets/logos/alpha_connect_shortlogo_dark.svg /tmp/opencode/icon-192.png
     convert -background none -resize 512x512 mobile/assets/logos/alpha_connect_shortlogo_dark.svg /tmp/opencode/icon-512.png
     ```
   - If neither available, install: `apt-get install -y librsvg2-bin` or `apt-get install -y imagemagick`
   - **If none of the above tools can be installed**, use a Python script with `cairosvg` as fallback:
     ```bash
     pip install cairosvg Pillow
     python3 -c "
     import cairosvg
     for size in [16, 32, 192, 512]:
         cairosvg.svg2png(url='mobile/assets/logos/alpha_connect_shortlogo_dark.svg', write_to=f'/tmp/opencode/icon-{size}.png', output_width=size, output_height=size)
     "
     ```

2. Replace favicon (use 32x32 for `favicon.png`):
   ```bash
   cp /tmp/opencode/favicon-32.png mobile/web/favicon.png
   ```

3. Replace PWA icons:
   ```bash
   cp /tmp/opencode/icon-192.png mobile/web/icons/Icon-192.png
   cp /tmp/opencode/icon-512.png mobile/web/icons/Icon-512.png
   ```

4. For maskable icons, the SVG content should be padded with a background. Maskable icons need a "safe zone" (circle inscribed in the icon). Since the α mark is on transparent background, create maskable versions with `#111317` (dark surface) background:
   - Using rsvg-convert + ImageMagick composite, or Python:
     ```python
     from PIL import Image
     for size in [192, 512]:
         bg = Image.new('RGBA', (size, size), (0x11, 0x13, 0x17, 255))
         icon = Image.open(f'/tmp/opencode/icon-{size}.png').convert('RGBA')
         # Center the icon at 80% of the canvas (safe zone)
         inner = int(size * 0.8)
         icon_resized = icon.resize((inner, inner), Image.LANCZOS)
         offset = (size - inner) // 2
         bg.paste(icon_resized, (offset, offset), icon_resized)
         bg.save(f'/tmp/opencode/maskable-{size}.png')
     ```
   ```bash
   cp /tmp/opencode/maskable-192.png mobile/web/icons/Icon-maskable-192.png
   cp /tmp/opencode/maskable-512.png mobile/web/icons/Icon-maskable-512.png
   ```

5. Verify all files exist and have non-zero size:
   ```bash

   ```
