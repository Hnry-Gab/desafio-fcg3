**Create `mobile/lib/features/staff/models/banner_model.dart`:**
```dart
class BannerModel {
  final String id;
  final String imageUrl;
  final bool isEnabled;
  final int displayOrder;
  final DateTime createdAt;
  final DateTime updatedAt;

  BannerModel({required this.id, required this.imageUrl, required this.isEnabled, required this.displayOrder, required this.createdAt, required this.updatedAt});

  factory BannerModel.fromJson(Map<String, dynamic> json) => BannerModel(
    id: json['id'],
    imageUrl: json['image_url'],
    isEnabled: json['is_enabled'] ?? true,
    displayOrder: json['display_order'] ?? 0,
    createdAt: DateTime.parse(json['created_at']),
    updatedAt: DateTime.parse(json['updated_at']),
  );

  /// Full URL for loading image. Relative `image_url` field is served under /uploads/
  String get fullImageUrl => '/uploads/$imageUrl';
}
```

**Create `mobile/lib/features/staff/services/banner_service.dart`:**
- Import DioClient from `mobile/lib/core/network/dio_client.dart`
- Class `BannerService` with `final DioClient _dio;` constructor param
- Methods:
  - `Future<List<BannerModel>> fetchAll()` — GET `/banners/all`, parse list
  - `Future<BannerModel> upload(Uint8List bytes, String filename, String mimeType)` — POST `/banners/upload` with `FormData` containing `MultipartFile.fromBytes(bytes, filename: filename, contentType: MediaType.parse(mimeType))`
  - `Future<BannerModel> toggleEnabled(String id, bool enabled)` — PUT `/banners/$id` body `{"is_enabled": enabled}`
  - `Future<void> deleteBanner(String id)` — DELETE `/banners/$id`
- Note: Use `import 'package:http_parser/http_parser.dart'` for `MediaType` (already a dependency in the project from booking_flow_sheet pattern)
- Use `import 'package:dio/dio.dart'` for `FormData`, `MultipartFile`

**Create `mobile/lib/features/staff/providers/banner_management_provider.dart`:**
- `final bannerServiceProvider = Provider<BannerService>((ref) => BannerService(ref.read(dioClientProvider)));`
- `final bannersProvider = AsyncNotifierProvider<BannersNotifier, List<BannerModel>>(BannersNotifier.new);`
- `BannersNotifier extends AsyncNotifier<List<BannerModel>>`:
  - `build()`: call `ref.read(bannerServiceProvider).fetchAll()`, return list
  - `Future<void> upload(Uint8List bytes, String filename, String mimeType)`: call service, then `ref.invalidateSelf()`
  - `Future<void> toggle(String id, bool enabled)`: call service, update local state optimistically
  - `Future<void> delete(String id)`: call service, remove from local state

**Create `mobile/lib/features/staff/screens/staff_banner_management_screen.dart`:**
- `class StaffBannerManagementScreen extends ConsumerWidget`
- AppBar: title `'Gerenciar Banners'`, actions: `[AppBarActions()]`
- FAB: `FloatingActionButton` with `Icons.add`, onPressed opens file picker:

  - If file selected: call `ref.read(bannersProvider.notifier).upload(file.bytes!, file.name, mimeTypeFromExtension)`

  - Show SnackBar on success ("Banner adicionado") or error (red SnackBar)
- Body: `RefreshIndicator` wrapping the content
  - On `bannersProvider` loading → `AppSkeletonList()`
  - On error → `AppErrorState(onRetry: ...)`
  - On data with empty list → `AppEmptyState(message: 'Nenhum banner cadastrado')`
  - On data with items → `GridView.builder` with `crossAxisCount: 2`, `childAspectRatio: 0.85`
    - Per D-10: Each grid item is a `GlassCard` containing:
      - `ClipRRect` with `borderRadius: BorderRadius.circular(AppSpacing.radiusMd)` wrapping `Image.network(banner.fullImageUrl, fit: BoxFit.cover, height: 120)` — thumbnail
      - Row below with: `Switch` widget for enable/disable toggle (per D-12), value = `banner.isEnabled`, onChanged calls `ref.read(bannersProvider.notifier).toggle(banner.id, !banner.isEnabled)`
      - Badge: small Container with `banner.isEnabled ? 'Ativo' : 'Inativo'` text, green/red background
      - `IconButton(Icons.delete_outline, color: colors.error)` — onPressed shows confirmation dialog (`AlertDialog` with "Excluir banner?" / "Cancelar" / "Excluir"), on confirm calls `ref.read(bannersProvider.notifier).delete(banner.id)`
    - Wrap each grid item in `AnimatedEntrance(delay: AppAnimations.getEntranceDelay(index))`
- Per D-11: No live carousel preview at top — grid of cards is sufficient
- Use `ResponsiveContainer` wrapping the content (consistent with all staff screens)
- Helper function `_mimeTypeFromFilename(String name)`: extension lookup → 'image/jpeg', 'image/png', 'image/webp'

**Image URL construction:** The backend stores `image_url` as relative path (e.g., `banners/abc_photo.jpg`). The Flutter app must prepend the base URL. In `BannerService` or in the screen, construct full URL as `${DioClient.baseUrl}/uploads/${banner.imageUrl}`. Check how existing image URLs are constructed in the project (e.g., document file_url pattern) and follow the same approach.
