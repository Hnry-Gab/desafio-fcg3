Create `backend/src/features/banners/controllers.py`:

Define `banners_router = APIRouter(prefix="/banners", tags=["banners"])` with 5 endpoints:

1. **GET /banners** (public for students — per D-13 staff+provider manage, students just view):
   - No auth dependency required — this is a public listing of enabled banners for the student carousel
   - Calls `banner_service.list_banners(db, enabled_only=True)`
   - Returns `list[BannerResponse]`
   - Per BNNR-01/BNNR-02: returns only enabled banners ordered by display_order

2. **GET /banners/all** (staff/provider — management listing):
   - Auth: `user: UserContext = Depends(get_current_user_or_service)`, then `require_staff(user)`
   - Calls `banner_service.list_banners(db, enabled_only=False)`
   - Returns `list[BannerResponse]`
   - Per BNNR-05: shows all banners including disabled for management preview

3. **POST /banners/upload** (staff/provider — per D-07, D-13):
   - Auth: `require_staff(user)`
   - Params: `file: UploadFile = File(...)`
   - Validate content_type in `["image/jpeg", "image/png", "image/webp"]` — else 400 `INVALID_FILE_TYPE`
   - Validate file size <= 2MB (2 * 1024 * 1024 bytes) by reading `await file.read()` — else 400 `FILE_TOO_LARGE`
   - Save to `uploads/banners/{uuid4}_{original_filename}` (UUID prefix pattern from existing uploads)
   - Create banner record with `image_url = f"banners/{filename}"`
   - Return `BannerResponse` with status 201

4. **PUT /banners/{banner_id}** (staff/provider — per D-12):
   - Auth: `require_staff(user)`
   - Body: `BannerUpdate`
   - Calls `banner_service.update_banner(db, banner_id, data)`
   - Returns `BannerResponse`
   - Per D-12: toggle is_enabled, optionally update display_order

5. **DELETE /banners/{banner_id}** (staff/provider — per D-13, BNNR-04):
   - Auth: `require_staff(user)`
   - Calls `banner_service.delete_banner(db, banner_id)` to get `image_url`
   - Delete file from disk: `os.remove(f"uploads/{image_url}")` wrapped in try/except (ignore if missing)
   - Return 200 `{"deleted": true}`
