**Create `mobile/lib/features/client/providers/banner_provider.dart`:**
- Simple `FutureProvider` (no need for full Notifier since students only read):
```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../../staff/models/banner_model.dart';  // reuse model
import '../../../core/network/dio_client.dart';

final studentBannersProvider = FutureProvider<List<BannerModel>>((ref) async {
  final dio = ref.read(dioClientProvider);
  final response = await dio.get('/banners');  // public endpoint, no auth needed for listing
  final List<dynamic> data = response.data is List ? response.data : response.data['items'] ?? [];
  return data.map((json) => BannerModel.fromJson(json)).toList();
});
```
- Note: The GET /banners endpoint is public (no auth). The DioClient may still send the auth header but that's fine — the backend ignores it for this endpoint.
- Check how dioClientProvider is exported/imported in the project and follow the same pattern.

**Create `mobile/lib/features/client/screens/widgets/banner_carousel.dart`:**
- `class BannerCarousel extends StatefulWidget` (needs Timer + PageController state)
  - Constructor: `final List<BannerModel> banners;` and `final String baseUrl;` (the API base URL for constructing full image URLs)
  - If `banners.isEmpty` → return `const SizedBox.shrink()` (per D-04: 0 banners = invisible)
  - If `banners.length == 1` → return single static image, no animation, no dots (per D-04)

- `_BannerCarouselState extends State<BannerCarousel>`:
  - Fields:
    - `late PageController _pageController;`
    - `Timer? _autoScrollTimer;`
    - `int _currentPage = 0;`
  - `initState()`:
    - `_pageController = PageController();`
    - If `widget.banners.length > 1`: call `_startAutoScroll();`
  - `dispose()`:
    - `_autoScrollTimer?.cancel();`
    - `_pageController.dispose();`
  - `_startAutoScroll()`:
    - `_autoScrollTimer = Timer.periodic(const Duration(seconds: 4), (_) { ... });` (per D-01: 4-5 seconds)
    - Inside timer: calculate next page. Per D-05 (continuous loop): if at last page, animate to page 0; else animate to next page.
    - Use `_pageController.animateToPage(nextPage, duration: const Duration(milliseconds: 500), curve: Curves.easeInOut)` for smooth transition
  - `_onPageChanged(int page)`:
    - `setState(() => _currentPage = page);`
  - `_onManualSwipe()` (called when user starts dragging):
    - `_autoScrollTimer?.cancel();` (per D-02: pause auto-scroll on manual swipe)
    - Start a delayed timer to resume: `Future.delayed(const Duration(seconds: 6), _startAutoScroll)` (resume after ~6s idle)
  - `build()`:
    - Return `Column` with:
      1. `ClipRRect` with `borderRadius: BorderRadius.circular(AppSpacing.radiusMd)` wrapping:
         - `SizedBox(height: 180)` (per D-08: fixed height; agent's discretion on exact value)
         - Contains `NotificationListener<ScrollNotification>` wrapping `PageView.builder`:
           - `controller: _pageController`
           - `onPageChanged: _onPageChanged`
           - `itemCount: widget.banners.length`
           - `itemBuilder`: returns `Image.network(fullUrl, fit: BoxFit.cover, width: double.infinity, height: 180)` (per D-08: BoxFit.cover)
           - Wrap Image.network with `loadingBuilder` showing a shimmer/placeholder while loading
           - Wrap Image.network with `errorBuilder` showing a grey placeholder with broken image icon
         - `onNotification` on ScrollNotification: detect `ScrollStartNotification` from user drag → call `_onManualSwipe()`
      2. Per D-03: Dots indicator below carousel (only if banners.length > 1):
         - `const SizedBox(height: 8)`
         - `Row(mainAxisAlignment: MainAxisAlignment.center)` containing dots:
         - For each banner index, render `AnimatedContainer`:
           - width: `_currentPage == i ? 24 : 8`, height: 8
           - decoration: BoxDecoration with `borderRadius: BorderRadius.circular(4)`, color: `_currentPage == i ? colors.primary : colors.onSurfaceVariant.withValues(alpha: 0.3)`
           - `duration: const Duration(milliseconds: 300)`
         - This creates the standard expanding-dot pattern (active dot is wider)

**Full image URL construction:**
The `BannerModel.imageUrl` is a relative path like `banners/abc_photo.jpg`. The carousel needs the full URL. Get the base URL from DioClient configuration. The constructor takes `baseUrl` param, and the full URL is `$baseUrl/uploads/${banner.imageUrl}`. Alternatively, if the project has a global API URL constant, use that. Check how existing image URLs are handled in the project and follow the same approach.

// Banner carousel (per BNNR-01: below greeting card)
bannersAsync.when(
